# 🧊 Marching Cubes - Procedural Terrain with Real-Time Deformation (Unreal Engine 5)

This project is a custom implementation of the **Marching Cubes algorithm** in **C++** within **Unreal Engine 5**, designed to generate and modify procedural terrain in real time. It supports dynamic terrain deformation and visual feedback using a custom material shader.

## 🚀 Features

- ✅ Procedural terrain generation using **3D Perlin Noise**
- ✅ **Real-time terrain deformation** (hole creation via raycast)
- ✅ Chunk-based system for **performance optimization**
- ✅ Mesh generation using `UProceduralMeshComponent`
- ✅ Optimized **triangulation and interpolation** via lookup tables
- ✅ Custom **vertex-color-based material** to display terrain changes (e.g. destruction in red)
- ✅ Integration with **Niagara VFX** (projectiles, explosions)
- ✅ Uses **Observer pattern** (Listener) for interaction between C++ and Blueprints

---

## 🧠 How It Works

- A 3D **density matrix** is generated using **Perlin Noise** to simulate natural terrain.
- Each voxel is evaluated against an **isovalue threshold** to determine surface intersections.
- A **triangulation table** with 256 configurations defines how the surface intersects each cube.
- Geometry is generated by interpolating edge positions and creating triangle lists.
- Terrain is split into **chunks** for modular updates and performance.
- A raycast system lets the player **destroy terrain in real time** by modifying voxel density.
